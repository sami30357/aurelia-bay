Aurelia Bay is a 3D open-world crime game in a sun-soaked coastal city at golden hour. You are back after five years away: Rico needs a driver, the cops need a target, and the whole sunset coast is yours to take. Explore on foot or by stolen car, outrun the police across a 5-star wanted level, run six story missions, pick up taxi fares, and smuggle crates by speedboat under a setting sun that turns the whole bay neon at night.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network, everything is vendored under game/.

## Controls

| Key | Action |
| --- | --- |
| W A S D | Move / drive (A D steer in a car) |
| Shift | Sprint |
| Mouse drag | Camera |
| Click | Shoot (on foot) |
| F | Punch |
| E | Enter / steal a car, take the boat, get out |
| T | Pick up a waving fare (in a car) |
| R | Next radio station |
| M | Mute |
| P | Pause |

Progress (mission, cash, fares) saves to localStorage — Continue on the title screen picks it up.
